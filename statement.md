# Hospital Management System – Project Statement

## 1. Problem Statement

Managing hospital records manually can be time-consuming and may lead to errors. Patient details, doctor information, and appointments need to be organized properly. This project provides a simple Java-based system to manage these basic hospital activities efficiently.

## 2. Scope of the Project

The project focuses on managing basic hospital information such as:

* Patient records
* Doctor records
* Appointment details
* Patient searching
* Viewing stored information

The system can be further expanded with billing, medicines, rooms, and permanent data storage.

## 3. Target Users

The system is mainly designed for:

* Hospital receptionists
* Hospital staff
* Doctors
* Small clinics
* Students learning Java and OOP

## 4. High-Level Features

* Add and view patient details
* Add and view doctor details
* Search patients by ID
* Book appointments
* View appointments
* Simple menu-driven interface
* Patient and doctor ID validation
* Organized management of hospital records
